## Normalization Rules and Caption Architecture

### Syntax Constraints That Silently Break Hashtag Indexing

One of the most frequent technical mistakes in hand-typed social captions is introducing punctuation or hyphenated compound terms inside a hashtag. Social parsers terminate a hashtag token at the first non-alphanumeric boundary—meaning `#tailwind-css` indexes only `#tailwind`, `#local-seo` breaks into `#local`, and `#don'tquit` truncates to `#don`. Internally, the generator sanitizes every raw database entry and custom seed keyword before deduplication:

```typescript
// Standardize hashtag token: single leading '#', ASCII alphanumerics only
const normalizeHashtag = (raw: string): string => {
  const cleaned = raw.replace(/#/g, "").replace(/[^a-zA-Z0-9]/g, "").trim();
  return cleaned.length > 0 ? `#${cleaned}` : "";
};

// Example: "local-seo, next.js 15" -> ["#localseo", "#nextjs15"]
```

When a niche keyword falls outside the 18 curated verticals (such as a specialized SaaS product or regional sport), the fallback engine sanitizes the token and synthesizes prefix/suffix compounds (`motivation`, `tips`, `hacks`, `vlog`, `setup`, `aesthetic`, `tok`, `reels`) until the 60-tag candidate pool is populated for mixing.
