# Säure-Base-Rechner: Neutralisation verstehen

Was passiert, wenn man eine gefährliche Säure mit einer gefährlichen Base mischt? Sie zerstören sich gegenseitig!
Das nennt man eine **Neutralisationsreaktion**. Sie heben sich auf und hinterlassen nur harmloses Salzwasser. Wir erklären, wie das funktioniert, die Mathematik der Titration, und unseren [Säure-Base-Rechner](/de/rechner/saeure-base-rechner).

---

## 💥 Die Neutralisationsreaktion

Die Grundregel lautet:
**Säure + Base $\rightarrow$ Salz + Wasser**
* Die Säure gibt ein Wasserstoffion ($H^+$) ab.
* Die Base gibt ein Hydroxidion ($OH^-$) ab.
* Sie verbinden sich zu Wasser ($H_2O$).
* Die restlichen Atome bilden ein Salz.

---

## 🧪 Was ist eine Titration?

Im Labor hat man oft eine Säure mit *unbekannter* Konzentration. Um diese zu ermitteln, führt man eine **Titration** durch.
Man tropft langsam eine Base (*bekannter* Konzentration) in die Säure, bis die Lösung neutral ist (pH 7). Über die Menge der Base berechnet man die Stärke der Säure!

**Die Formel:**
**$M_a \times V_a = M_b \times V_b$**
* $M_a$ = Molarität der Säure
* $V_a$ = Volumen der Säure
* $M_b$ = Molarität der Base
* $V_b$ = Volumen der Base
