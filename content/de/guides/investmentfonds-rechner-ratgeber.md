# Investmentfonds erklärt: So bauen Sie ein diversifiziertes Portfolio auf

Alles auf eine Aktie zu setzen, ist extrem riskant. Das Geheimnis ist **Diversifikation**. Der einfachste Weg dorthin ist ein **Investmentfonds**. Wir erklären, wie Fonds funktionieren und wie Sie unseren [Investmentfonds-Rechner](/de/rechner/investmentfonds-rechner) nutzen.

---

## 🧺 Was ist ein Investmentfonds?

Stellen Sie sich einen riesigen Korb vor. Tausende Anleger legen ihr Geld zusammen, und ein Manager kauft davon Hunderte verschiedene Aktien.
* **Aktive Fonds:** Ein Manager wählt Aktien aus (hohe Gebühren).
* **Passive Fonds (ETFs/Indexfonds):** Kaufen automatisch den ganzen Markt (sehr niedrige Gebühren).

---

## 🛑 Der Renditekiller: Die Gesamtkostenquote (TER)

Fonds erheben eine jährliche Verwaltungsgebühr.
Eine Gebühr von 1 % klingt nach wenig, kann aber über 30 Jahre bis zu **30 % Ihres Gesamtertrags** auffressen. Kaufen Sie immer kostengünstige Indexfonds (0,05 % bis 0,20 %)!

---

## ⚙️ Nutzung des Investmentfonds-Rechners

1. **Ihr Investment:** Startkapital und monatliche Sparrate.
2. **Erwartete Rendite:** Z.B. 7 % oder 8 % jährlich.
3. **Kostenquote (TER):** Die jährliche Gebühr des Fonds.
4. **Berechnen:** Das Tool zeigt, wie groß Ihr Vermögen wird und exakt, wie viel Geld Sie an Gebühren verlieren!
