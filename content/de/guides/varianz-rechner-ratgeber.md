# Varianz verstehen: Populations- vs. Stichprobenformeln

In der Statistik misst die **Varianz**, wie weit eine Menge von Zahlen von ihrem Durchschnittswert (dem Mittelwert) gestreut ist.

In diesem Leitfaden untersuchen wir die Formeln und die Verwendung unseres [Varianzrechners](/de/rechner/varianz-rechner).

---

## 🧮 So berechnen Sie die Varianz

### Populationsvarianz (σ²)
Verwenden Sie dies, wenn Sie Daten von *jedem einzelnen Mitglied* der Gruppe haben.
1. Finden Sie den Mittelwert.
2. Subtrahieren Sie den Mittelwert von jedem Punkt.
3. Quadrieren Sie jede Abweichung.
4. Addieren Sie sie.
5. Teilen Sie durch die Gesamtzahl ($N$).

### Stichprobenvarianz (s²)
Wir verwenden **Bessels Korrektur**: Teilen Sie durch die Gesamtzahl *minus eins* ($n - 1$).
