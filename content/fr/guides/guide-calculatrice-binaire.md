# Comprendre le Binaire : Comment Pensent les Ordinateurs

Chaque photo sur votre téléphone est une séquence de 1 et de 0. Comment est-ce possible ? Dans ce guide, nous expliquerons le système en Base 2 et comment utiliser notre [Calculatrice Binaire](/fr/calculatrices/calculatrice-binaire).

---

## 🔟 Base 10 (Décimal) vs Base 2 (Binaire)

Nous utilisons la **Base 10** (chiffres de 0 à 9).
Les ordinateurs utilisent la **Base 2** (seulement 0 et 1).
* Zéro = 0
* Un = 1
* Deux = 10
* Trois = 11

---

## 💡 Pourquoi les Ordinateurs Utilisent-ils le Binaire ?

Un ordinateur est composé de milliards d'interrupteurs (transistors) qui n'ont que deux états :
* **ALLUMÉ** (Le courant passe) = 1
* **ÉTEINT** (Le courant est bloqué) = 0
Il est beaucoup plus fiable de détecter si le courant passe ou non, plutôt que de mesurer 10 niveaux de tension différents.

---

## 🧮 Comment Lire le Binaire

En Base 10 : Unités, Dizaines, Centaines.
En Base 2, ça double : 1, 2, 4, 8, 16.
Le nombre **1011** :
(1×8) + (0×4) + (1×2) + (1×1) = **11**.
