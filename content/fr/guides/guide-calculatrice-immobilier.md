# ROI Immobilier : Comment Analyser une Propriété d'Investissement

Acheter un bien locatif est une voie éprouvée vers la richesse, mais acheter la *mauvaise* propriété peut épuiser vos économies. Dans ce guide, nous explorerons les métriques et comment utiliser notre [Calculatrice Immobilière](/fr/calculatrices/calculatrice-immobilier).

---

## 🏢 Les 3 Métriques d'Or

### 1. Bénéfice d'Exploitation Net (NOI)
* **Formule :** Revenus Locatifs Bruts - Dépenses d'Exploitation
* *Note :* N'inclut pas votre paiement hypothécaire.

### 2. Taux de Capitalisation (Cap Rate)
Le taux de rendement si vous achetiez **comptant**.
* **Formule :** NOI / Prix d'Achat

### 3. Rendement Cash-on-Cash (CoC)
Mesure le rendement annuel sur l'*argent réel investi* (mise de fonds).
* **Formule :** Flux de Trésorerie Annuel / Argent Total Investi
