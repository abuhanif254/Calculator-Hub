# Formule Empirique : Le Ratio le Plus Simple

Si vous analysez une poudre mystérieuse composée de 40.0% de Carbone, 6.7% d'Hydrogène et 53.3% d'Oxygène (en masse), comment savoir de quoi il s'agit ? Vous devez trouver sa **Formule Empirique**. Découvrez comment et utilisez notre [Calculatrice de Formule Empirique](/fr/calculatrices/calculatrice-formule-empirique).

---

## 🔬 Qu'est-ce qu'une Formule Empirique ?

C'est le **rapport de nombres entiers le plus simple** des atomes d'un composé. Elle ne donne pas le nombre total d'atomes, mais leur *proportion*.
Par exemple, le Peroxyde d'Hydrogène est $H_2O_2$. Sa formule empirique est simplement **HO** (le ratio est de 1 pour 1).

---

## 🧮 Comment la Calculer

Avec notre poudre mystérieuse :

**Étape 1 : Base de 100 grammes**
Les pourcentages deviennent des grammes : 40.0g C, 6.7g H, 53.3g O.

**Étape 2 : Convertir en Moles**
Divisez par la masse atomique de chaque élément.
* C : 40.0 / 12.01 = 3.33 moles
* H : 6.7 / 1.008 = 6.64 moles
* O : 53.3 / 16.00 = 3.33 moles

**Étape 3 : Diviser par le plus petit**
Divisez toutes les valeurs par la plus petite (3.33).
* C : 3.33 / 3.33 = **1**
* H : 6.64 / 3.33 = **2**
* O : 3.33 / 3.33 = **1**

Le ratio est 1:2:1. La formule empirique est **$CH_2O$**.
